## 💸 Featured Project: Splitr
**Split group expenses fairly and settle up.** It's an installable PWA that syncs live between group members and keeps working offline.

🔗 [Live app](https://splitr-bills.web.app) · [Website](https://www.splitr.workers.dev) · [Source](https://github.com/anpixelartist/Splitr)

- **Cent-exact maths:** equal or exact-amount splits in any currency, with a minimal "who pays whom" settlement plan (unit-tested in `settlement.ts`).
- **Real-time and offline-first:** Firebase Auth + Cloud Firestore with offline persistence. Guest users can upgrade to Google sign-in without losing data.
- **Security in the rules:** Firestore security rules are the single source of truth, covered by emulator-based tests.
- **AI connector (MCP):** a remote MCP server on Cloudflare Workers with OAuth 2.1 + PKCE. Every request runs with the user's own Firebase ID token, so the assistant can't see or do anything the user couldn't do in the app. No admin keys involved.
- **Stack:** React 19, TypeScript, Vite, Tailwind, Firebase, Cloudflare Workers, Vitest.
